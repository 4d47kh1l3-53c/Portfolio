About

I specialize in identifying and mitigating security risk across web applications, APIs, mobile platforms, and internal Active Directory environments. My approach is risk-based — testing efforts stay aligned to what actually matters to the business, not just what's easiest to flag.

Across roles at TCS and Qseap Infotech, I've run 90+ penetration tests on web, mobile and API applications, coordinated annual VAPT programs across multiple business verticals, and reviewed and validated assessment reports for technical accuracy before they reach stakeholders. I've also mentored junior consultants on methodology, vulnerability validation, and secure reporting.

Currently, I'm expanding into AI and LLM security — prompt injection, insecure output handling, agentic tool abuse, and the OWASP Top 10 for LLM Applications — while continuing to build toward security engineering and technical leadership.

Core expertise

Web application security

End-to-end security assessments of web applications, identifying vulnerabilities in authentication, authorization, session management, and business logic. Grounded in the OWASP Top 10, with emphasis on exploitability and real business impact.

API security

Security testing of REST and SOAP APIs — authentication bypass, BOLA/IDOR, mass assignment, rate-limiting gaps, and injection. Focused on the failure modes traditional web testing tends to miss.

Mobile application security

Static and dynamic analysis of Android applications — insecure storage, certificate pinning bypass, WebView flaws, and insecure API communication, using tools like APKTool, JADX, Frida, and Objection.

Active Directory & internal network

Internal network and Active Directory security testing — enumeration, credential attacks, lateral movement, and privilege escalation paths using BloodHound, Impacket, Rubeus, Mimikatz, and Kerbrute.

Risk assessment & threat modeling

Systematic risk assessments and threat identification to help organizations prioritize security investment based on likelihood, impact, and business context — not just CVSS scores.

LLM / AI security

Emerging focus on large language model and agentic AI security — prompt injection, insecure output handling, excessive agency, and the OWASP Top 10 for LLM Applications.

Approach

Security is fundamentally about managing risk. My approach prioritizes understanding business context, identifying the most critical assets, and focusing testing effort where it delivers the greatest value.

  1. Understand
  2. Threat model
  3. Test
  4. Exploit
  5. Validate
  6. Report
  7. Remediate
  8. Retest

Effective security work also requires clear communication — I translate technical findings into business impact so stakeholders can make informed decisions about remediation priorities.

Security isn't just about finding vulnerabilities — it's about building trust and creating lasting improvements, not just generating reports.
